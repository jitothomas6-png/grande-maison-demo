# Grande Maison — Sales & Billing Demo

GitHub Pages-ready static build from the saved HTML export (October 31, 2026).

## Publish using GitHub website (no terminal)
1. Create a new GitHub repository (prefer **Private** if the client has not approved public exposure).
2. Extract this ZIP locally. GitHub does not automatically extract ZIP uploads.
3. In the repository choose **Add file > Upload files**. Upload `index.html` and `.nojekyll` (README optional), then commit.
4. Go to **Settings > Pages > Build and deployment**; choose **Deploy from a branch**, **main**, **/(root)**, then Save.
5. Open the Pages URL shown in Settings. For project repositories it normally follows `https://USERNAME.github.io/REPOSITORY/`.

## Important scope
This archive contains the HTML demo export only. It does not include Cloudflare Workers, D1 database, backend secrets, server-side authentication or live data synchronization. Do not treat it as a secure production ERP or upload sensitive customer details to a public GitHub Pages demo. GitHub Pages sites are publicly accessible even when the repository is private.
